### React Osaka
React Osaka is a bi-lingual community for [React.js](http://react.js/) users in Kansai supported by [OKTech](http://oktech.jp/).
We organize our events both in English and Japanese to invite a broader community to our events.
React Osaka は関西の [React.js](http://react.js/) ユーザーのための [OKTech](https://oktech.jp/) に支えられているバイリンガルコミュニティです。
より多くの人に参加していただくために、イベントを英語と日本語の両方で開催しています。

We will support with translation.
言語については運営サポートします。

React Osaka 専用の Discord をメンテします、気軽にご参加ください。
We have a dedicated React Osaka discord server, please feel free to join it!
→ https://discord.gg/Ke34JUmJDy
