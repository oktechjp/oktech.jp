Approaching Autumn, we are using September to look into how we can improve the experience of working with the command line.

Do you use the command line or terminal? If not, then possibly its because its too boring?

We will make the CLI a little more joy with an introduction to [Mise-en-dev](https://mise.en.dev/) by Austin.
